规则说明（连拍 / 推荐 / 色彩变体 / 删除 / 关闭）

关闭方式：点顶部“停止服务”，窗口会连同本地服务一起关闭；在启动终端按 Ctrl+C 也会干净停止。服务只监听本机 127.0.0.1，不对外开放。想再用时，重新打开 Shiying-3.3.0（app_native）即可。

导出说明：导出的清单只含相对扫描文件夹的相对路径与文件夹名称，不含完整本机路径、用户名或盘符；删除仍只在待删篓里二次确认后执行。

人脸诚实说明：Haar 级联只能框出脸，做不了“认出同一个人”。真实人脸聚类必须走特征向量 + 聚类路线；本机若无可用模型，界面显示的即为测试分组或无分组，绝不冒充真实人脸识别。合成卡通测试图不能验证真实人脸聚类，真实人脸聚类需用真实照片在真机环境验证。

语义找图说明：默认走本机 Chinese-CLIP 离线模型，模型不随主包捆绑，首次点“建立语义索引”时才下载（约 190 MB，只需一次）。索引按文件内容 sha256 存向量，暂停后已算好的部分会落盘，下次按差集续算；删除文件后会同步剔除向量。置信度由实测余弦线性映射成 0~100 分，分宽松 / 标准 / 严格三档；演示图是合成图，真实照片上的效果须真机复测。

API 精排说明：默认关闭，只有你本次手动勾选才会调用。只上传本地粗筛前 20 张候选的 200×200 低清拼图（2 张拼图）与搜索词，不上传原图与完整路径；请求超时 9 秒，失败或无 Key 自动退回本地结果。Key 用 Windows DPAPI 加密保存（绑定当前账户），界面与日志只显示掩码。
