人物墙

待删确认篓

篓子里的文件还没删。点“二次确认删除”后会再弹一次确认框，只有你第二次点头，文件才会被移入系统回收站（若系统不支持，则移入工具包内的 .trash_backup 隔离文件夹），绝不直接彻底删除。

规则说明（连拍 / 推荐 / 色彩变体 / 删除 / 关闭）

关闭方式：点顶部“停止服务”，窗口会连同本地服务一起关闭；在启动终端按 Ctrl+C 也会干净停止。服务只监听本机 127.0.0.1，不对外开放。想再用时，重新打开 Shiying-3.2.0（app_native）即可。

导出说明：导出的清单只含相对扫描文件夹的相对路径与文件夹名称，不含完整本机路径、用户名或盘符；删除仍只在待删篓里二次确认后执行。

人脸诚实说明：Haar 级联只能框出脸，做不了“认出同一个人”。真实人脸聚类必须走特征向量 + 聚类路线；本机若无可用模型，界面显示的即为测试分组或无分组，绝不冒充真实人脸识别。合成卡通测试图不能验证真实人脸聚类，真实人脸聚类需用真实照片在真机环境验证。
